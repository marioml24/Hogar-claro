HOGARCLARO PWA - Versión inicial

1. Abre index.html en tu ordenador para explorar la interfaz. El modo instalable/offline requiere servirla desde HTTPS o localhost.
2. Para publicar gratis: crea un repositorio GitHub con los cuatro archivos de esta carpeta y activa GitHub Pages en Settings > Pages > Deploy from a branch > main /root. Espera a que aparezca la URL HTTPS.
3. En iPhone: abre la URL en Safari > Compartir > Añadir a pantalla de inicio.
4. En Android: abre la URL en Chrome > menú > Instalar aplicación o Añadir a pantalla de inicio.
5. La información se guarda en localStorage del navegador, sin cuenta ni sincronización. Usa Ajustes > Exportar copia JSON periódicamente. El borrado de datos del navegador puede eliminar los registros.
6. No hay pasarela de pago ni bloqueo por licencia. Para cobrar 4,99 EUR antes del acceso, necesitaremos una capa de autenticación, backend y verificación de pagos; no es seguro ocultar un enlace público como mecanismo de pago.
7. Los datos iniciales son ficticios. En Ajustes > Empezar desde cero puedes borrarlos.
